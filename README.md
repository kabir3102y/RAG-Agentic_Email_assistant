# RAG-Agentic_Email_assistant
**RAG in ML** usually means Retrieval-Augmented Generation.
It’s a technique where an AI model:
Retrieves relevant information from a database or documents.
Augments the user’s question with that information.
Generates an answer using the retrieved context.
**Agentic AI/ML** means AI systems that can act autonomously to achieve a goal, rather than only responding to a prompt.

A RAG-based agentic email assistant is an AI system that retrieves relevant information from emails and knowledge bases, uses an LLM-based agent to reason and plan, and can execute email-related actions such as drafting, categorizing, searching, scheduling, or sending emails through external tools.
